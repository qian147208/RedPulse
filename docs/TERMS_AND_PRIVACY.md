# 灵芯 用户服务条款

最后更新:2026 年 6 月 26 日

## 1. 协议范围与接受

灵芯(以下简称"本应用")是一款面向内容创作者的桌面端工具,帮助用户在小红书等平台发布前,通过 AI 生成文案、配图和视频。

**下载、安装或使用本应用,即视为你已阅读、理解并同意本条款全部内容。** 如果你不同意,请立即停止使用并卸载本应用。

本应用当前为个人开发者作品,非商业实体运营。

## 2. 应用功能

本应用提供以下功能:

- **文案生成**:基于关键词或产品信息,通过第三方 AI 服务生成小红书风格笔记(标题、正文、标签)
- **图片生成**:通过第三方 AI 服务生成配图(支持文生图、图生图)
- **视频生成**:通过第三方 AI 服务生成 5 秒竖屏短视频(9:16)
- **AI 助手**:基于对话形式给出小红书内容优化建议
- **本地存储**:所有生成记录保存在你的设备本地(沙箱内)
- **历史记录**:你可以在应用内浏览、编辑、删除生成历史

## 3. 账户与认证

本应用**不提供账户系统**,不收集你的姓名、邮箱、手机号等个人信息。你不需要注册或登录即可使用全部功能。

## 4. 第三方 AI 服务

本应用本身**不运行 AI 模型**,所有生成能力由以下第三方服务提供。你使用本应用的 AI 功能,即视为你同意对应第三方服务的服务条款与隐私政策:

| 服务 | 用途 | 链接 |
|---|---|---|
| Agnes(Agnes AI) | 文案、图片、视频生成 | https://apihub.agnes-ai.com |
| DeepSeek | 文案生成 | https://www.deepseek.com |
| 火山引擎方舟(Doubao) | 视频生成 | https://www.volcengine.com |

**你输入的所有内容(关键词、产品描述、参考图、对话消息)都会发送到上述第三方服务**,由其处理并返回结果。请勿在输入中包含个人敏感信息(身份证号、银行账号、医疗记录等)。

## 5. API Key 与计费

### 5.1 内置 Key
本应用代码中嵌入了一个 Agnes API Key 作为默认配置,**仅用于让用户在不填写自己的 Key 时也能体验功能**。这个 Key 由开发者承担费用。

如果你希望长期使用,**强烈建议你在「设置 → API 配置」中填写自己的 Key**,这样:
- 调用更稳定
- 数据走你自己的额度
- 不受内置 Key 的调用限制影响

### 5.2 用户自填 Key
你填写的 API Key **仅存储在你设备的 UserDefaults 中**,不会上传到任何服务器。但请注意:
- 本地存储**未加密**(沙箱本身受系统保护,普通用户无法读取)
- 你卸载本应用 = Key 自动删除
- 你切换设备 = 需要在新设备上重新填写

### 5.3 第三方服务计费
使用 Agnes / DeepSeek / 方舟的 AI 能力会**由对应服务商按调用量计费**。具体费率由第三方决定,与本应用无关。
- 使用内置 Key 时:费用由开发者承担
- 使用你自己 Key 时:费用从你的账户扣除

# 灵芯 隐私政策

最后更新:2026 年 6 月 26 日

## 1. 我们收集什么

**简短回答:几乎不收集任何东西。**

本应用的所有数据都存储在你的设备本地(沙箱),不上传到开发者服务器。

### 1.1 我们**不收集**的信息
- 你的姓名、邮箱、手机号、身份证号
- 你的设备型号、操作系统版本(除了调用系统 API 必需的)
- 你的 IP 地址、地理位置
- 你的使用行为、点击记录
- 任何形式的分析数据

### 1.2 我们**存储在你本地**的数据
| 数据 | 存储位置 | 用途 |
|---|---|---|
| 生成记录(标题、正文、标签、图片URL、视频URL) | 设备沙箱(SwiftData) | 应用内历史记录浏览 |
| 产品库信息 | 设备沙箱(SwiftData) | 复用产品信息生成内容 |
| 灵感条目 | 设备沙箱(SwiftData) | 内容创作参考 |
| AI 对话历史 | 设备沙箱(SwiftData) | 多轮对话上下文 |
| 用户反馈 | 设备沙箱(SwiftData) | 你主动提交的问题反馈 |
| 你填写的 API Key | 设备 UserDefaults | 调用第三方 AI 服务 |
| 你填写的 API Base URL | 设备 UserDefaults | 自定义 API endpoint |
| 下载的视频文件 | 设备沙箱 `Documents/videos/` | 视频预览(24h 远程 URL 过期后本地播放) |

**卸载本应用 = 上述全部数据立即删除,无法恢复。**

### 1.3 我们**发送给第三方**的数据
使用 AI 生成功能时,你输入的内容会发送给对应的第三方 AI 服务:

| 输入 | 接收方 | 接收方用途 |
|---|---| |
| 关键词、产品描述、产品图(参考图) | Agnes | 文案/图片/视频生成 |
| 关键词、对话消息 | DeepSeek | 文案生成 |
| 视频提示词、参考图 | 火山引擎方舟 | 视频生成 |

**这些数据由第三方服务按其隐私政策处理,我们不存储副本,也不做二次利用。**

## 2. 我们如何保护你的数据

### 2.1 数据安全
- 所有数据存储在 macOS / iOS 沙箱内,受系统保护
- 不上传开发者服务器 = 不存在我们的服务器被攻击导致泄露的风险
- API Key 仅存本地 UserDefaults,沙箱隔离保护普通用户无法读取

### 2.2 已知的局限
- UserDefaults **未加密**(macOS / iOS 沙箱本身提供隔离,但高级攻击者可读取)
- 如果你**和别人共享设备**,对方可能看到你的生成历史
- 如果你的设备**未设锁屏密码**,设备丢失时他人可读取本地数据

## 3. 第三方服务的隐私实践

你输入的内容会经过以下第三方:

## 4. 儿童隐私

## 5. 你的权利

由于数据全部存在本地,你拥有完全控制权:

- **查看**:应用内可查看所有生成记录、对话历史、反馈

- **撤回授权**:由于无账户系统,不存在"撤回授权"概念

- 火山引擎:境内(中国大陆)

**跨境传输情况取决于你使用的 provider**,请参考对应服务商的隐私政策。

如果上架 App Store,需要在 App Store Connect 的"App 隐私"中声明:

- **不收集数据(Collected Data Types)** ✅ — 因为我们不收集
- **不追踪(Tracking)** ✅ — 因为无追踪 SDK

**关键点**:Apple 的"Collected"指从设备传出去并由开发者(或代理开发者)处理的数据。我们不存用户输入,所以严格来说不"收集";但需在隐私标签里说明"内容会上传到第三方 AI 服务"。
